Cancel a run

Usage: alloy cancel [OPTIONS] --run <RUN>

Options:
      --run <RUN>              Run id
      --workspace <WORKSPACE>  Workspace root used to resolve config files and `.alloy` (CL2) [default: .]
      --profile <PROFILE>      Catalog profile id: default | autonomous | readonly (CL4)
      --json                   Emit machine-readable JSON on stdout (CL3)
      --quiet                  Suppress progress rendering on stderr (CL7)
      --verbose                Raise the tracing filter (CL7)
  -h, --help                   Print help
